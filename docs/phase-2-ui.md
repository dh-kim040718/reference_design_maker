# Phase 2 화면·사용자 흐름

2026-10-29 최종 구현 기준. 이전 텍스트 와이어프레임을 현재 동작에 맞춰 정리했다. [검증 기록](./phase-2-verification.md), [API 계약](./phase-2-api.md), [썸네일 상세](./thumbnail-ui.md)를 함께 참고한다.

## 핵심 흐름

회원가입·로그인 → 프로젝트 목록 → 프로젝트 카드에서 레퍼런스 추가 → URL·유형 선택 → 선택 제목·디자인 메모 → 저장 → 유형별 목록 → 상세·메모 수정.

프로젝트를 먼저 열어 산출물 유형을 만든 다음 유형 카드에서 추가할 수도 있다. 추가 폼에서도 프로젝트·유형을 만들 수 있다. 진입 경로를 자동 선택하고, 별도 진입 시 계정의 마지막 저장 위치를 제안한다.

## 화면과 주소

| 주소 | 화면 | 주요 동작 |
|---|---|---|
| `/login` | 로그인 | 이메일·비밀번호, 실패 안내, 회원가입 이동 |
| `/signup` | 회원가입 | 이메일·8자 이상 비밀번호·확인, 자동 로그인 또는 이메일 확인 안내 |
| `/projects` | 프로젝트 목록 | 생성, 열기, 카드에서 레퍼런스 추가, 이름 변경, 보관·복구 |
| `/projects/:projectId` | 프로젝트·유형 목록 | 유형 생성, 열기, 레퍼런스 추가, 이름 변경, 보관·복구 |
| `/projects/:projectId/types/:typeId` | 레퍼런스 목록 | 썸네일 카드, 상세, 원본 열기, 추가 |
| `/references/new` | 레퍼런스 추가 | URL·분류·선택 제목·메모, 썸네일 미리보기·선택·붙여넣기 |
| `/references/:referenceId` | 목록·상세 분할 화면 | 같은 유형의 다른 항목 탐색, 이미지·분류·원본 확인, 메모·썸네일 수정 |

루트와 로그인 상태의 로그인 주소는 프로젝트 목록을 표시한다. 목록의 보관 상태·페이지와 상세 진입의 복귀 경로를 유지한다. 새로고침·직접 URL 진입을 지원하며, 없는 항목은 프로젝트 목록으로 돌아가는 안내를 제공한다.

## 추가 패널

최대 너비 980px의 패널을 사용한다. 큰 소개 제목 대신 작은 제목과 닫기를 둔다.

- 왼쪽: URL → 프로젝트·산출물 유형 → 선택 제목 → 선택 디자인 메모(기본 3줄) → 취소·저장.
- 오른쪽: 실제 저장될 카드 미리보기, 썸네일 이미지 선택·제거, 이미지 붙여넣기 안내.
- 설명 필드는 제거했다. 기존 description은 DB에 남기되 표시하지 않는다.
- 링크 입력 뒤 대표 이미지·제목을 조회한다. 직접 수정한 제목과 사용자가 선택한 이미지는 자동 결과로 덮어쓰지 않는다.
- 프로젝트 변경 시 유형을 초기화한다. 해당 프로젝트의 활성 유형만 선택한다. 보관되었거나 다른 계정에 속한 마지막 경로는 자동 선택하지 않는다.
- 저장 중에는 제출을 막고, 서버 성공 응답 후 해당 목록으로 이동한다. 실패 시 입력을 유지한다. 네트워크 단절로 결과를 알 수 없으면 목록 확인을 안내하고 자동 재전송하지 않는다.

## 카드와 상세 패널

카드는 썸네일·제목·출처·최대 두 줄 메모·원본 링크를 표시한다. 제목이 없으면 도메인을 사용한다. 프로젝트·유형 표지는 이미지가 있는 최근 수정 레퍼런스를 사용하고, 새 프로젝트는 기본 아이콘을 사용한다. 카드의 열기 안내와 추가 버튼은 실제 링크다.

상세는 최대 1080px 안에서 왼쪽 목록과 오른쪽 선택 패널을 나란히 둔다. 선택 패널의 상단은 이미지와 제목·분류·원본 링크를 가로로 배치한다. 그 아래에 메모와 저장·수정일을 둔다.

- 이미지 선택·링크에서 불러오기는 동일한 높이·너비의 버튼으로 한 줄 정렬한다.
- Ctrl+V 도움말과 실패 안내는 버튼 행 밖에 둔다.
- 제목·분류·원본 링크의 왼쪽 기준선과 글자 간격을 맞춘다.
- 디자인 메모 제목·수정 버튼은 같은 행에 정렬하고, 메모 내용은 별도 배경으로 구분한다.
- 날짜는 보조 영역, 저장 성공 알림은 작은 상태 표시로 둔다.
- 이미지가 없는 기존 항목은 상세에서 한 번 자동 조회한다. 실패해도 원본 링크·메모는 그대로 사용한다.

## 썸네일 입력

PNG·JPEG·WebP 파일 선택과 이미지 복사 후 Ctrl+V를 지원한다. 원본은 10MB 이하로 받고 브라우저에서 카드 크기로 줄여 저장한다. 자동 미리보기 제한과 저장 정책은 [썸네일 문서](./thumbnail-ui.md)를 참고한다. 확인한 Pinterest 링크의 자동 수집은 제한되며, 직접 입력한 썸네일은 정상 저장·표시된다.

## 보관·인증·오류 상태

프로젝트·유형 보관 전 기존 연결이 유지되고 새 항목을 추가할 수 없다는 확인을 받는다. 보관함에서 조회·복구할 수 있다. 보관된 경로는 원본 열기만 가능하며 메모·이미지 수정·추가를 막는다. 프로젝트 복구는 개별 유형의 기존 보관 상태를 유지한다. 영구 삭제 버튼은 없다.

인증 확인 중에는 계정 데이터를 보여주지 않는다. 갱신 실패 시 로그인으로 전환하고, 현재 탭 메모리의 초안은 같은 계정으로 재로그인한 경우에만 복구한다. 로그아웃 시 세션·초안·계정별 화면 상태를 지운다.

조회 로딩·빈 목록·조회 실패·검증 오류·저장 중·저장 실패·성공을 구분한다. 입력값은 실패 시 유지하고 첫 오류 필드로 포커스를 이동한다. 성공 알림은 서버 응답으로만 생성하며 URL 매개변수만으로 성공을 표시하지 않는다.

## 스타일과 접근성

따뜻한 밝은 배경, 흰색 패널, 녹색 강조색을 유지한다. 주요 제목 24~32px, 본문 14~16px, 보조 글자 11~13px를 사용한다. 이미지·메모·원본 관련 동작을 묶고 패널 높이를 불필요하게 늘리지 않는다.

작은 화면에서는 추가 화면을 한 열로, 상세 화면은 목록 패널을 숨긴 한 열로 표시한다. 다이얼로그는 포커스 이동·복귀와 Escape 닫기를 제공하며 입력 레이블, 키보드 포커스, 텍스트 오류 안내와 상태 알림을 사용한다. 실제 터치·스크린리더 검증은 후속 확인 대상이다.
