# 2026-11-03 변경 정리

## 프로젝트와 AI 시안 흐름

- 프로젝트를 열면 레퍼런스를 바로 표시하고 분류를 필터로 제공한다.
- 프로젝트/AI 화면의 헤더를 공유하고 분류 관리를 별도 패널로 모았다.
- 프로젝트 전체, 분류별, 명시적으로 체크한 레퍼런스의 이미지·메모 종합 생성을 지원한다.
- 카드 체크박스, 전체 선택·해제, 부분 선택 상태와 선택 개수를 제공한다.
- 현재 요구사항·추가 요청을 생성 CTA에서 직접 전송한다. 우선순위는 추가 요청 → 요구사항 → 메모다.
- 저장된 이미지를 CTA에서 자동 준비하며 실패한 카드에만 교체 기능을 표시한다.
- 썸네일·제목·메모 중심의 2열 카드, 큰 미리보기, 소속 태그와 모바일 배치를 정리했다.

## 서버와 운영 준비

- `0009_project_concepts` 마이그레이션, 프로젝트 입력 스냅샷·이력·선택 범위 검증을 추가했다.
- Pinterest 공개 핀 메타데이터를 통한 미리보기 복구 경로를 추가했다.
- 저장 이미지 준비는 인증·소유권·공개 IP·리다이렉트·용량·형식 검증을 적용하며 원본은 영구 저장하지 않는다.
- 명시적으로 승인한 신규 예산 기간을 지원한다. 과거 사용량 미확인 기록과 전체 예약 원장은 보존한다.
- 프로젝트 시안의 백업·복원 및 컨테이너 준비 검증을 보완했다.

- 프론트: 62개 테스트 통과, 빌드·린트 통과.

- 공개 산출물 비밀값 검사 및 변경 소스의 키 패턴 검사 통과.
- 이전 작업 중 Chrome 데스크톱·모바일의 라이브러리/AI 화면과 선택 동작을 검증했다.
- 이번 검증에서는 실제 유료 이미지 생성 요청을 보내지 않았다.

`.env`, 로컬 DB, 업로드 이미지, 브라우저 계정·스크린샷, 백업 파일은 Git에 포함하지 않는다.
신규 환경에서는 서버 실행 전에 DB 마이그레이션을 적용해야 한다. 실제 배포·원격 백업 연결과
미확인 과거 청구 내역 확인은 별도 잔여 작업이다.
