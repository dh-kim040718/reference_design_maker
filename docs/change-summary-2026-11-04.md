# 참고 요소·영역 메모 변경 정리

마지막 커밋 `cfd0833` 이후 변경사항.

- 레퍼런스별 참고 특징 16개를 스타일·구조·UI 요소로 묶어 복수 선택한다.
- 각 특징은 짧은 설명을 제공하고 생성 프롬프트에 의미를 전달한다.
- 이미지 드래그 또는 정규화 좌표 입력으로 최대 6개의 영역 메모를 저장한다.
- 기존 디자인 메모와 함께 생성 입력에 포함하며, 완료 결과의 입력 스냅샷에도 보존한다.
- 이미지 교체 후에는 영역을 재확인해야 생성할 수 있도록 UI와 API에서 검사한다.
- 편집 화면은 특징 선택, 이미지·메모 좌우 배치, 하단 취소·저장 순서로 정돈했다.
- 모바일은 이미지 아래에 영역 메모를 표시한다.
- 원본 이미지 추가 보관 없이 특징·좌표·메모와 이미지 버전만 저장한다.
- 발전 방향 조사와 기능 사용 안내를 문서화했다.

## 적용

새 스키마는 `0010_reference_guidance`이다. 기존 환경은 backend에서
`.venv\Scripts\python.exe -m alembic upgrade head` 실행 후 서버를 시작한다.
로컬 환경에는 백업 후 마이그레이션을 적용했다.
이전 백업을 읽을 때 새 nullable 필드를 보완한다.
참고 요소가 존재하면 데이터 손실을 막기 위해 해당 마이그레이션 다운그레이드를 차단한다.

## 검증

- 프런트엔드 전체 테스트: 71개 통과, 빌드·린트 통과.
- 백엔드 전체 테스트: 148개 통과, PostgreSQL 전용 74개 제외.
- 기존 브라우저 검증에서 드래그·저장·새로고침 유지·세로 이미지·모바일 가로 넘침 확인.
- 공개 배포 파일 비밀정보 검사 통과. 유료 API 생성 호출 없음.

API 키·예산 등 로컬 `.env`, DB, 백업, 브라우저 테스트 계정과 스크린샷은 커밋하지 않는다.
새 참고 요소가 실제 생성 품질에 미치는 효과는 추후 별도 유료 비교 검증 대상이다.
