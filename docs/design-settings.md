# 시안 사용 목적과 출력 규격

생성 준비 화면의 ‘시안 설정’에서 용도와 크기를 지정한다.

- 용도 21개: 자유 시안·직접 입력, 웹·앱, 콘텐츠·광고, 인쇄·편집, 브랜드·그래픽.
- 목적 목록은 용도명과 기본 크기를 좌우로 표시한다. 선택 시 단위·가로·세로·ppi를 함께 적용한다.
- 선택 후 수치를 수정할 수 있고 재렌더·재생성 복원으로 수정값을 기본값으로 덮어쓰지 않는다.
- ‘직접 입력’으로 전환하면 현재 크기와 해상도를 유지한다. 같은 용도를 다시 선택하면 기본 규격으로 돌아간다.
- A4/A5는 종이 규격이다. 앱·웹·광고·패키지는 단일 표준이 없으므로 자주 쓰는 추천 기본값이며 실제 납품 규격에 맞게 수정한다.
- 단위: px, mm, cm, in, pt. 백분율 대신 가로·세로 값을 직접 입력한다.
- 물리 단위에는 해상도(ppi)를 제공한다. 기본 300ppi, 36~600ppi 정수.
- 단위를 바꾸면 기존 픽셀 크기를 기준으로 수치를 변환한다. mm/cm는 소수 둘째 자리에서 표시 반올림한다.
- 환산: inch=25.4mm=2.54cm=72pt, pixel=inch×ppi. 최종 픽셀은 양수 반올림한다.
- 출력은 한 변 16~8192px, 합계 1600만 픽셀, 가로·세로 길이 차이 3배 이내로 제한한다.
- 설정이 잘못되면 유료 요청 전에 차단한다. 크기·단위·ppi 설정이 본문의 상충하는 크기 지시보다 우선한다.

## 실제 생성과 출력

현재 모델은 [OpenAI 공식 출력 규격](https://developers.openai.com/api/docs/guides/image-generation)에 따라
각 변 16의 배수, 최대 3840px, 면적 655360~8294400px, 비율 1:3~3:1을 사용한다.
요청 규격과 가까운 유효 AI 원본 크기를 계산해 실제 API `size`에 전달한다.
원본은 결과를 자르거나 늘여 찌그러뜨리지 않고 요청한 출력 크기에 맞춘다.
비율 차이는 흰 여백으로 맞추고, 원본보다 큰 출력은 확대한다. 이 차이는 입력 화면에서 펼쳐 확인할 수 있다.
PNG에 입력 ppi를 해상도 메타데이터로 저장한다. 래스터 시안이며 벡터·CMYK·재단선 출력은 포함하지 않는다.

단위·ppi·용도·입력 수치·출력 픽셀·AI 원본 크기는 결과 스냅샷에 남긴다.
같은 요청 ID에서 설정을 바꾸면 재시도 요청을 거절하며, 재생성 준비에서는 저장한 설정을 복원한다.
기존 API 호출과 과거 결과에는 설정이 없어도 1024×1024 기본 동작을 유지한다. DB 마이그레이션은 없다.

검증은 mock 공급자·HTTP transport와 로컬 이미지로 수행하며 유료 API를 호출하지 않는다.
