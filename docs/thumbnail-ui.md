# 썸네일과 간결한 레퍼런스 UI

2026-10-29 사용자 요청에 따라 설명 입력을 없애고 썸네일 중심으로 추가·조회 화면을 정리했다.

## 화면 동작

- 추가 화면은 최대 980px 작업 패널이다. 왼쪽에 URL·분류·제목·디자인 메모, 오른쪽에 저장될 카드 미리보기를 둔다. 메모 입력은 기본 3줄이다.
- 설명 필드는 입력·상세 표시에서 제거한다. 기존 description 데이터는 삭제하지 않으며 이전 API 입력과 호환된다.
- URL 입력 후 대표 이미지·제목을 조회한다. 직접 입력한 제목과 직접 선택한 이미지를 자동 결과로 덮어쓰지 않는다. 조회가 끝나지 않거나 실패해도 링크는 저장할 수 있다.
- 자동 이미지를 사용할 수 없으면 PNG·JPEG·WebP를 직접 선택한다. 브라우저에서 최대 720×540의 WebP 썸네일로 줄여 저장하며 원본 업로드 파일은 보관하지 않는다. 선택 원본은 10MB 이하, 저장 이미지는 300KB 이하로 제한한다.
- 레퍼런스 카드는 이미지·제목·출처·짧은 메모를 보여준다. 프로젝트·유형 카드는 해당 경로의 최근 수정된 이미지 있는 레퍼런스를 표지로 사용한다. 레퍼런스가 없는 새 프로젝트는 기본 아이콘을 사용한다.
- 상세 화면은 같은 유형의 레퍼런스 목록과 선택 항목을 나란히 배치한다. 이미지 옆에 제목·분류·원본 링크를 두고, 그 아래에 디자인 메모를 표시한다. 모바일은 목록 패널을 숨기고 한 열로 표시한다.
- 기존 항목에도 상세의 이미지 선택·링크에서 불러오기를 사용할 수 있다. 보관된 경로는 이미지도 변경할 수 없다.

## API·DB

- `0003_thumbnails` 마이그레이션으로 `references.preview_url`, `preview_source`를 추가했다.
- `POST /api/v1/references/preview`: 인증된 사용자가 원본 URL의 공개 메타데이터를 조회한다.
- `PATCH /api/v1/references/{id}/thumbnail`: 소유권 및 보관 상태를 확인한 후 썸네일을 수정한다.
- 프로젝트·유형 목록 응답은 `thumbnail_url`, 레퍼런스 응답은 `preview_url`, `preview_source`를 포함한다.
- 메타데이터 수집은 robots.txt를 확인하며 공개 HTTP(S) 주소만 사용한다. DNS 결과의 모든 주소를 검사하고 검증된 IP에 연결하며 TLS 호스트 검증을 유지한다. 리다이렉트별 주소·robots 재확인, DNS/연결 제한, HTML 512KB 제한을 적용한다. 쿠키나 로그인 정보는 외부로 전송하지 않는다.
- 직접 선택한 이미지의 MIME·크기·파일 헤더를 검사하고 SVG는 허용하지 않는다.

## 검증과 한계

최신 검증은 프런트엔드 테스트 19개, 백엔드 전체 53개(빠른 테스트 39개·PostgreSQL 14개)와 린트·타입 검사·빌드 통과다. Chrome·Edge에서 직접 이미지 선택 → 저장 → 메모 수정 → 새로고침 후 이미지 표시 → 모바일 너비 → 로그아웃을 검증했다. Chrome에서는 이미지 붙여넣기와 최종 정렬도 확인했다.

최종 상세 정렬에서는 이미지 버튼을 동일한 높이·너비의 한 행으로 맞추고 Ctrl+V 안내를 별도 줄로 분리했다. 제목·분류·원본 링크의 기준선, 메모 제목·수정 버튼의 행 높이, 메모 배경과 날짜 보조 영역도 정돈했다. 사용자가 해당 변경을 확인했다.

자동 미리보기는 외부 사이트의 공개 메타데이터·robots·접근 허용 여부에 따라 달라진다. 외부 HTTPS 인증서 목록 문제는 certifi 공개 CA 목록을 기존 신뢰 저장소에 추가해 수정했으며 TLS 인증서·호스트 검증은 유지한다. 이미지가 만료되거나 차단되면 깨진 이미지 대신 미리보기 없음 상태를 표시한다.

### Pinterest 링크 재점검

사용자가 제공한 Pinterest Pin URL은 인증서 설정 수정 후에도 자동 가져오기가 불가능했다. Pinterest robots 정책은 등록되지 않은 수집기의 접근을 제한한다. 공개 oEmbed 경로도 정책을 확인한 뒤에만 사용하며, 차단 상태에서는 요청하지 않는다. 접근 제한을 우회하거나 이미지를 추정해 표시하지 않는다.

기존에 썸네일이 없는 항목은 상세 진입 시 한 번 자동 재조회한다. 실패하면 직접 이미지 선택 방법을 표시한다. 원본 사이트에서 이미지를 복사한 뒤 Ctrl+V로 붙여넣는 입력도 추가했다. 파일 선택과 같은 크기·포맷 검증 및 썸네일 저장을 사용한다.

참고: [Pinterest 접근 정책](https://www.pinterest.com/robots.txt), [Pinterest 공식 위젯 문서](https://developers.pinterest.com/docs/web-features/widgets/), [WordPress의 Pinterest oEmbed 공급자 정의](https://github.com/WordPress/WordPress/blob/master/wp-includes/class-wp-oembed.php).
