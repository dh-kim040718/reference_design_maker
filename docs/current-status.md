# 현재 제품 범위와 확인 기준

기준일: 2026-11-05. 과거 단계 문서의 실행 기록은 당시 증거이며 현재 화면 설명과 구분한다.

## 첫 출시 범위

레퍼런스를 프로젝트·분류에 저장하고 썸네일·메모·참고 요소를 확인한 뒤, 선택한 이미지와 메모를 종합해 한 장의 AI 탐색 시안을 만든다. 결과는 본인만 조회·다운로드·삭제하며 기존 입력을 가져와 다른 시안을 요청할 수 있다.

| 항목 | 현재 범위 | 남은 확인 |
|---|---|---|
| 계정·자료 관리 | 가입·로그인·계정 격리, 프로젝트·분류 보관/복원 | 운영 환경 회귀 |
| 레퍼런스 저장 | URL·선택 제목/메모·썸네일, 확장 0.3.0 자동 추출 및 실패 시 대안 | 출처별 실제 페이지·실기기 확인 |
| 참고 요소 | 16개 역할·최대 6개 영역 메모, 이미지 교체 시 영역 재확인 | 실제 생성의 반영 품질 평가 |
| 생성 범위 | 현재 프로젝트 또는 분류, 체크한 1~16개 이미지·메모 사용 | 다량 자료의 성능 평가 |
| 시안 설정 | 사용 목적별 추천 크기, px/mm/cm/in/pt, 물리 단위 ppi, 직접 수정 | 새 규격 조합의 실제 결과 품질·비용 |
| 요구사항 | 별도 저장 버튼 없이 생성 CTA에서 현재 입력 반영. 추가 요청 → 프로젝트 요구사항 → 메모 순서. 크기 설정은 본문의 상충 크기보다 우선 | 작성 중 새로고침 시 초안 자동 복원은 없음 |
| 생성 안정성 | 중복 방지·예약 예산·UTC 일일 횟수 제한·상태 조회 복구 | 실제 청구 대조·운영 부하 |
| 결과 | 비공개 이미지·입력 스냅샷·다운로드·삭제·재생성 진입 | 사용자 유용성 수용 |
| 운영 준비 | 로컬 백업/격리 복원·컨테이너·운영 점검 CLI·CI 구성 | HTTPS 배포·원격 백업·알림·최신 원격 CI 결과 |

현재 결과는 래스터 탐색 시안이다. mm/cm와 ppi를 지정해도 벡터·CMYK·재단선이 제공되는 것은 아니다. 제공자 원본 크기와 최종 출력 크기는 다를 수 있다.

## 제외와 후속 기능

- 영역 편집: 실제 평가에서 보호 영역 보존 미달로 출시 제외. 로컬 영역/마스크 도구는 품질 합격 증거가 아니다.
- 서버 재시작 후 자동 재개: 원본 비보관 정책에 따라 제외.
- 검색·비교·채택·일괄 정리·협업: 후속 후보이며 현재 MVP 완료를 위한 필수 추가가 아니다.
- 비밀번호 재설정·계정 영구 삭제·보존 기간: 운영 공개 범위를 정할 때 정책과 구현 범위를 결정한다.
- 유료 API 호출·예산 증액·운영 배포는 일반적인 개발 지시로 자동 승인되지 않는다.

| 검증 대상 | 확인할 내용 | 증거 위치 |

| 선택 생성 | 선택한 범위만 사용, 누락/중복/초과/변경 입력 차단 | backend/tests/test_project_concepts.py, frontend/src/ProjectGenerationPage.test.tsx |
| 규격 | 단위 환산·경계값·출력 PNG 크기·재생성 복원 | backend/tests/test_design_settings.py, frontend/src/DesignSettingsFields.test.tsx |
| 조회 복구 | 일시 오류 복구·재시도 상한·수동 확인·페이지 이탈 정리·유료 POST 없음 | frontend/src/GenerationPage.test.tsx |

테스트 파일이 존재한다는 것과 해당 환경에서 이번에 실행했다는 것은 구분한다. PostgreSQL 통합 테스트 제외를 통과로 계산하지 않는다. 과거 단일 이미지 성공만으로 최신 다중 입력·참고 역할·출력 규격의 품질을 승인하지 않는다.

## 이번 보완

상태 조회 복구·전체 목록과 생성 입력 수 제한 분리, 생성 전 차단 조건 통합, 루트 작업 규칙과 문서 진입점을 정리했다. 구현/회귀 검증에 실제 유료 호출은 사용하지 않는다.

다음 필수 게이트는 실제 사용성·품질·청구 수용과 운영 대상 결정 후의 출시 검증이다. 초안 복원과 다량 자료 성능은 다음 사용성 보완 후보로 유지한다.
