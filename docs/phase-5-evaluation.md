# Phase 5 품질 평가표 — 실행 전 준비

실제 API 연동과 유료 검증은 보류 중이다. 이 문서는 평가 양식과 제안 기준이며 사용자 합의나 실제 측정 결과로 간주하지 않는다. mock 성공은 시각 품질·제공자 마스크 준수·비용 검증을 대체하지 않는다.

## 최소 비교 계획

자체 제작/입력 권한이 확인된 이미지 하나, 같은 사각형 마스크, 같은 디자인 방향을 재사용한다. 먼저 전체 생성이 성공한 기존 결과를 확보한 뒤 진행한다. 실제 검증 전 모델/API 계약, 예상 단가와 총 잔여 예산, 정확한 호출 수를 확인하고 별도 승인을 받는다.

| 사례 | 기존 방향 | 새 지시 | 확인 목적 |
| --- | --- | --- | --- |
| 전체 재생성 | 현재 메모·이전 추가 요청 확인 | 대표 요청 1개 | 방향 유지·이전 결과 보존·별도 이력 |
| 영역 편집 A | 사이드바·카드·차트 유지 | 선택한 카드 여백 확대·색상 변경 | 선택 일치·명시 지시 반영 |
| 영역 편집 B | A와 동일 | 비움 | 선택 내부 변형·주변 보존 |

위 표는 최대 호출 승인이나 자동 실행 계획이 아니다. 기존 유효한 결과가 있으면 재사용하며 한 번에 한 요청만 실행한다. 동일 사례를 UI/문서 변경 때문에 재생성하지 않는다. 실패·응답 불명은 무조건 재시도하지 않고 사용 내역부터 확인한다.

## 건별 기록 양식

| 항목 | 기록 |
| --- | --- |
| 실행 시각·작업 ID·operation | 미실행 |
| 원본/마스크 해시·크기·선택 좌표 | 미측정 |
| 모델·크기·품질·새 요청 ID | 미확정 |
| 기존 방향·메모·선택 지시 구분 | 확인 대기 |
| 성공/실패/불명·안전한 오류 코드 | 미실행 |
| 지연 시간(ms)·토큰 사용량 | 미측정 |
| 실제 청구액·잔여 승인 예산 | 미확정 (사용량 없음≠0원) |
| 주변 영역 보존 | 1~5점·변경 위치/이유 |
| 선택 영역 일치 | 1~5점·선택 밖 변경 여부 |
| 지시 반영 또는 무지시 변형 유용성 | 1~5점·사용 가능 여부 |
| 시각 품질·기존 디자인 방향 유지 | 각 1~5점·문자/구조 문제 |
| AI 표시·다운로드·이력·삭제 | 통과/실패 |
| 중복 요청 재제출 | 같은 작업 ID·추가 제공자 호출 없음 |

보존 비교는 원본과 결과를 같은 크기로 정렬하고 보호 영역의 전후 차이를 확인한다. AI 표시용 하단 띠의 변경은 별도로 기록한다. 픽셀 차이만으로 유용성을 판정하지 않고 시각 검토를 함께 수행한다. 결과 크기가 다르면 크기 변환 사실도 기록한다.

## 제안 판정 기준 — 실측 전 합의 필요

- 공통 안전 기준: 비밀 노출 없음, 실패의 성공 처리 없음, 명시 요청당 제공자 호출 최대 1회, 결과 AI 표시 유지.
- 편집 품질 기준 제안: 주변 보존·선택 일치·방향 유지·유용성 각각 4/5 이상, 중요한 보호 영역의 의도하지 않은 구조 변경 없음.
- 시간·장당 비용: 최초 측정 후 사용자와 한도를 합의한다. 아직 숫자 기준은 확정하지 않는다.
- A/B의 결과와 실패율은 표본 수를 함께 제시한다. 소수 시안으로 서비스 전체 품질이나 실패율을 보장하지 않는다.
- 미검증 또는 기준 미달이면 영역 편집을 계속 비활성화한다. 저장 MVP와 로컬 마스크 도구는 별도로 사용할 수 있다.
