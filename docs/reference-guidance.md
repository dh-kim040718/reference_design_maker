# 레퍼런스 참고 역할과 영역 메모

레퍼런스 상세의 ‘참고 요소 지정’에서 선택적으로 지정한다. 기존 디자인 메모는 유지한다.

- 역할은 16개로 중복 없이 여러 개 선택할 수 있다.
  - 스타일: 분위기 / 컬러 / 타이포그래피 / 아이콘 / 이미지·일러스트
  - 구조: 레이아웃 / 여백·간격 / 정보 위계 / 정보 밀도
  - UI 요소: 컴포넌트 / 버튼·CTA / 내비게이션 / 입력·폼 / 테이블·리스트 / 차트·지표 / 테두리·입체감
- 각 항목에 설명 툴팁을 제공하고, 선택한 역할의 의미를 생성 프롬프트에 전달한다.
- 역할을 선택하지 않으면 기존처럼 전체 이미지를 참고한다.
- 영역: 이미지의 빈 곳을 드래그하여 새 영역을 만든다. 박스 안쪽을 잡아 이동하고 선택한 박스의 네 모서리를 잡아 크기를 바꾼다.
- 메모를 선택하면 해당 영역의 조절점이 표시된다. 이동·크기 조절은 이미지 경계 안으로 제한한다.
- 숫자·방향 버튼이 필요한 경우 각 메모의 ‘정밀 조정’을 펼친다. 위치와 크기는 백분율이며 입력칸은 2열로 정렬한다.
- 영역마다 참고할 내용을 적는다. 최대 6개, 메모는 각 500자까지다.
- 원본 이미지 대신 역할·메모·정규화 좌표와 미리보기 버전만 저장한다.
- 이미지를 바꾸면 이전 영역의 위치를 재확인하거나 삭제해야 생성할 수 있다.
- 생성 준비 카드에 역할과 영역 메모 개수를 표시하며, 메모를 펼쳐 확인할 수 있다.
- 선택한 레퍼런스의 참고 요소가 생성 프롬프트와 결과 입력 스냅샷에 포함된다.
- 기존 결과 스냅샷은 레퍼런스 수정 후에도 유지된다. 새 시안에는 현재 저장된 참고 요소가 사용된다.
- 역할은 생성 의도를 전달하는 지시이며 정확한 반영률이나 픽셀 보존을 보장하지 않는다.
- 저장·수정·화면 검토는 유료 생성 요청을 보내지 않는다.

저장 스키마: `0010_reference_guidance`. 기존 자료는 참고 요소 없이 호환된다.
백업 로더는 이전 `0009_project_concepts` 자료에 새 nullable 항목을 보완한다.
영역이 저장된 DB의 다운그레이드는 데이터 손실 방지를 위해 차단한다.
