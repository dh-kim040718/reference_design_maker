# UI 디자인 방향

사용자 선택: 노션처럼 간결한 흑백 디자인. 포인트 색상은 검은색으로 통일한다.

- 흰 캔버스, 무채색 텍스트와 보조 요소, 얇은 회색 구분선을 사용한다.
- 주요 CTA·현재 탭·선택된 필터·체크박스에는 검은색을 사용하고, 선택 배경·포커스는 회색으로 구분한다.
- 보조 버튼은 흰색 또는 회색으로 낮춰 주요 작업과 구분한다.
- 작은 모서리 반경과 일관된 입력창·메뉴·카드 스타일을 적용한다.
- 프로젝트와 분류 범위, 카드 선택 및 모바일 배치는 유지한다.
- AI 생성은 레퍼런스와 나란한 탭 대신 현재 범위의 ‘시안 만들기’ CTA로 진입한다.
- 생성 준비 화면에는 레퍼런스로 돌아가는 경로를, 라이브러리에는 ‘시안 이력’ 링크를 둔다.
- 레퍼런스 이미지 자체의 색상은 바꾸지 않는다.

`frontend/src/index.css`의 의미별 색상 변수를 공통 기준으로 사용하고,
`frontend/src/theme.css`에서 로그인·라이브러리·상세·AI 화면의 표현을 통일한다.
브랜드를 복제하지 않고 [Notion](https://www.notion.com/help/intro-to-workspaces)과
[Daum](https://www.daum.net/)을 시각적 방향의 참고로 사용한다.
